Your agent asks. You decide.

AI agents can already book flights and check out. Giving one your real card is a bad idea. Agent Wallet sits in between.

You set the rulesA budget per agent, a cap per purchase, allowed categories, blocked stores, and an auto-approve limit.
The agent asks for moneyOne MCP tool call, or one HTTP request, with the store, the amount and the reason.
Small buys go through. Big ones buzz your phone.Approve with one tap, or with Face ID for large or risky purchases. Anything against your rules is blocked.
The agent gets a one-time cardIt's locked to the approved amount and dies after one use. Your real card is never shared.

It watches out for you

🛡️

Scam radar

Catches fake stores like amaz0n-deals.com, gift card and crypto scams, double purchases, and unusual amounts. A flagged purchase is never auto-approved.

💰

Price checks

"$16 cheaper at Target." Before you approve, it checks other stores, and the agent can switch.

🔐

Face ID approvals

Big or risky purchases need your face or fingerprint (passkeys), so a stolen password alone can't approve them.

📊

Insights

What each agent spent, where, on what, and how much your rules stopped.

Works with any agent

Claude, Cursor or any MCP client in one line. Everything else via a small HTTP API with an OpenAPI spec.

claude mcp add agent-wallet \
  -e WALLET_URL=https://your-wallet.app \
  -e WALLET_AGENT_KEY=aw_agent_... \
  -- npx -y -p github:HeyanshShah/agent-wallet agent-wallet-mcp
POST /v1/purchases

An open standard, not a walled garden

Card networks and payment companies are each building agent payments on their own rails. Agent Wallet is the neutral layer on the person's side, built on an open spec any agent or wallet can adopt: the Agent Spend Protocol.
